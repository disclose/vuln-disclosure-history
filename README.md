# Vulnerability Disclosure History

A people-centered history of vulnerability disclosure, coordinated vulnerability disclosure, and the rights of people who hack in good faith.

This repository backs the public disclose.io history page:

- https://disclose.io/history/

## What this project tracks

- Timelines compiled from primary sources
- People and organizations that shaped disclosure norms
- Documents, drafts, policies, and memos where provenance is known
- Lineage between disclosure language, practices, and communities

The project prioritizes attribution accuracy over narrative neatness. If a source is uncertain, the content should say so rather than overclaim.

## Contributing

If you worked on disclosure history, know of someone who should be credited, or have primary-source material to add, please open an issue or pull request.

Good contributions include:

- Primary source links
- Archived source links, such as Wayback Machine or archive.today snapshots
- Dates and names with clear uncertainty markers where needed
- Corrections to attribution or drafting lineage
